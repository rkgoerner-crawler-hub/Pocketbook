# Pocketbook

A simple household budget for a phone or tablet. Import bank statements (CSV), see where the money goes, set a monthly budget, find charges worth cutting, and plan debt payoff and savings.

**Your data stays on your device.** Everything is saved in the browser on the device that opens the app. Nothing is uploaded, and no account is needed. This repository holds only the app's code.

## Install on an Android phone or tablet

1. Open the app's web address in Chrome.
2. Tap the three-dot menu, then **Add to Home screen** (or **Install app**).
3. Open Pocketbook from the new icon from then on.

## Keep the data safe

Open the menu (three dots in the app) and use **Backup** about once a month. Use **Restore from a backup file** to load it on any device. Clearing Chrome's site data for this address erases the budget, so keep a recent backup.

## Getting a statement from Bank of America

1. Sign in at bankofamerica.com in a web browser.
2. Open the account, then tap **Download** above the transaction list.
3. Pick the dates, choose **Microsoft Excel Format** as the file type, and tap **Download Transactions**.
4. In Pocketbook, tap **Import a bank statement** and choose that file.
